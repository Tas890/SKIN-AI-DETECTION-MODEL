# SKIN-AI-DETECTION-MODEL
SkinAI Detection Model.  This repository contains a TensorFlow/Keras deep learning model for skin disease classification trained on merged dermatology image datasets.  The model can classify multiple skin conditions, including:  
Acne, Eczema, Fungal Infection, Melanoma, Psoriasis, and Vitiligo.

Model Information
Framework: TensorFlow / Keras
Architecture: MobileNetV2
Input Size: 224x224
Accuracy: ~75%

Training
The model was trained using Google Colab with merged and preprocessed Kaggle skin disease datasets.

Files
skin_model.keras → trained AI model
labels.txt → class labels
train_model.ipynb → training notebook
